# 04 — 範囲プリセット

## 目的

静止画へのドラッグ矩形選択で読み取り範囲をプリセットとして登録・編集・削除できるようにする。座標は相対値（0〜1）で保存。

- 参照: REQUIREMENTS.md §3.2、DESIGN.md §5（範囲選択オーバーレイ / ボタン）・§6（メイン・設定）
- 依存: 02, 03
- ⚠️ **ブラウザ実機での動作確認必須**

## Todo

## メモ

- 相対座標変換は「切り抜き」（チケット05）と対になるため、`presetRect ↔ pixelRect` の変換ユーティリティを共通化しておく
- 例プリセット名: 「ジャーナル」「コーデックス」「アイテム説明」
