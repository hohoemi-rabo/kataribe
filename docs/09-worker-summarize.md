## メモ

- ゴールドは summary-card 以外に絶対使わない（DESIGN.md の禁止事項）
- セクション0件（または範囲該当なし）時は生成ボタンを無効化し、案内を表示
- Worker 側の入力上限: 200セクション / 合計10万字（超過は400）。seq は送らず、プロンプト内で位置番号（【セクション1】…）を付与
- 「全部」でも `from_seq` / `to_seq` には実材料の min/max を記録
- 生成成功後に保存だけ失敗した場合はテキストを画面に残し「保存を再試行」で復旧（Gemini 再呼び出し不要）
