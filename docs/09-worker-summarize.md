# 09 — Worker: summarize + あらすじ画面

## 目的

本命機能。蓄積セクションのみを材料に「ここまでのあらすじ」を生成・保存・履歴表示・朗読する。ネタバレ防止が絶対条件。

- 参照: REQUIREMENTS.md §3.6・§6、DESIGN.md §5（summary-card）・§6（あらすじ）
- 依存: 07, 08

## Todo

### POST /summarize（Worker）

- [ ] リクエスト: セクションテキスト配列（+ ゲームタイトル）→ あらすじテキストを返す
- [ ] **ネタバレ防止プロンプト（Worker 側で固定付与。フロントから変更不可）**:
  - 「提供されたセクションのテキスト **のみ** を情報源とすること」
  - 「このゲームに関する外部知識・事前知識を一切使用しない。セクションに書かれていない人物・地名・出来事・今後の展開に言及してはならない」
  - 「推測で補完せず、書かれている範囲で構成すること」
- [ ] 出力スタイル指定: 「だ・である」ではなく語り聞かせる自然な口調（朗読前提）

### フロント: あらすじ画面

- [ ] `/summaries` 画面: 画面タイトル display-md「あらすじ」
- [ ] 生成フォーム: 範囲選択（filter-pill「全部」 or セクション範囲 N〜M 入力）+ button-primary「まとめる」
- [ ] 対象範囲のセクション `content` を取得して Worker へ送信 → 結果を `summaries` に保存（from_seq / to_seq / content）
- [ ] 生成結果を summary-card で表示: bg surface-elevated / padding 48px 32px / **上辺 4px ゴールドバー**（gold-start → gold-end 横グラデ）/ タイトル heading-xl weight 300 / 本文 body-md・行間 1.75・max-width 640px
- [ ] **生成中はゴールドバーが左右にゆっくり流れるシマー**（本アプリ唯一の演出）
- [ ] 生成したあらすじの読み上げ（player-bar。チケット07の共通再生系を使用）
- [ ] 履歴一覧: summary-card 縮小版（ゴールドバー維持 / padding 24px / 本文3行 clamp / 生成日時・対象範囲 caption-md）を縦積み。クリックで全文表示

### 動作確認

- [ ] セクション数件だけの状態で生成し、**セクションに無い固有名詞・展開が出てこない** ことを目視確認（有名ゲームで外部知識が混入しないかを重点確認）
- [ ] 範囲指定（N〜M）が効いている
- [ ] 履歴が残り、過去のあらすじも読み上げできる

## メモ

- ゴールドは summary-card 以外に絶対使わない（DESIGN.md の禁止事項）
- セクション0件（または範囲該当なし）時は生成ボタンを無効化し、案内を表示
