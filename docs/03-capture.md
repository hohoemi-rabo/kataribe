# 03 — 画面キャプチャ

## 目的

`getDisplayMedia` によるゲーム画面キャプチャと、ボタン押下時の1フレーム取得基盤を作る。本アプリのコア機能。

- 参照: REQUIREMENTS.md §3.1、DESIGN.md §5（preview-panel / badge-recording）・§6（メイン）
- 依存: 01, 02
- ⚠️ **ブラウザ実機での動作確認必須**（getDisplayMedia は自動テスト不可）

## メモ

- キャプチャ状態は複数チケットから参照するため、Context または カスタムフック（例: `useCapture`）に閉じる
- `'use client'` はキャプチャ関連コンポーネントの境界に置き、ページ全体をクライアント化しない
